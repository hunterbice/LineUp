- [ ] App name: LineUp
- [ ] Subtitle: Check the scene before you go
- [ ] Description accurately covers Early Access, venue status, Deals, favorites, and optional location
- [ ] Keywords avoid unsupported claims, excessive-drinking language, and competitor trademarks
